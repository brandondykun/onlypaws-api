# Logs Directory

This directory contains log files generated by the Only Paws API.

## Log Files

### Development
- `django-all.log` - All application logs
- `django-error.log` - Error logs only
- `celery.log` - Celery task logs
- `security.log` - Security events

### Test
- `django-test.log` - Test environment logs
- `django-test-error.log` - Test errors

### Staging
- `django-info.log` - Info logs (JSON, 50% sampled)
- `django-warning.log` - Warning logs (JSON)
- `django-error.log` - Error logs (JSON)
- `celery.log` - Celery logs (JSON, 50% sampled)
- `celery-error.log` - Celery errors (JSON)
- `security.log` - Security logs (JSON)
- `performance.log` - Performance issues (JSON)

### Production
- `django-info.log` - Info logs (10% sampled)
- `django-warning.log` - Warning logs
- `django-error.log` - Error logs
- `celery.log` - Celery logs (10% sampled)
- `celery-error.log` - Celery errors
- `security.log` - Security logs
- `performance.log` - Performance issues

## Quick Commands

```bash
# View all logs
tail -f django-all.log

# View errors only
tail -f django-error.log

# View last 100 lines
tail -100 django-error.log

# Search for specific text
grep "User login" django-all.log

# View logs from Docker container
docker exec -it onlypaws_django tail -f /vol/log/django-error.log
```

## Log Rotation

Logs automatically rotate when they reach their size limit:
- Rotated files are named: `django-error.log.1`, `django-error.log.2`, etc.
- Old logs are automatically deleted when backup count is reached
- No manual cleanup needed

## Notes

- Log files are **NOT** committed to Git (see `.gitignore`)
- Sensitive information is automatically redacted in staging/production
- Production logs use JSON format for easier parsing
- Log sampling reduces volume in production (10% of INFO logs)

For complete documentation, see: `docs/LOGGING.md`
